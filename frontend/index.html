Review 1 Talking Points

IRIS: Intelligent Resolution Incident System

1. Problem Statement

Engineers constantly face repeated technical issues. Traditional tools like Jira only store static tickets without intelligence, while generic ChatGPT lacks organizational memory. IRIS connects problems with historical database solutions using SQL.

2. Relational Design (1:N Schema)

problems table (Problem_ID PK, Title, Category, Status) linked to solutions table (Solution_ID PK, Problem_ID FK, Solution_Text, Source).

3. 30-Second Demo Flow

  1. Click preset "Slow API Response" and click "Log to Database & Analyze".
  2. Point out the SQL query box: "The database runs a relational JOIN to search historical fixes."
  3. Show the AI generated fix & click "Accept Solution & Update Database".
  4. Switch to "Database Explorer" tab to show the new record in the solutions table.
